# Security Policy

## Supported Versions
| Version | Supported |
|---------|-----------|
| 0.1.x   | ✅ Yes    |

## Reporting a Vulnerability
Email `security@ums.dev` with subject `[SECURITY]`. We will acknowledge within 48 hours.

## Production Security Checklist
- Set `ADMIN_API_KEY` in production
- Restrict CORS origins
- Configure rate limits
- Use PostgreSQL/MySQL instead of SQLite
- Always use HTTPS (reverse proxy)
